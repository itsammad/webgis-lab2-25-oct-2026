About this map

Study area: Islamabad Capital Territory and Rawalpindi (bounding box 33.55–33.80°N, 72.90–73.25°E).

Data: Live query to the OpenStreetMap Overpass API for communication masts and towers (man_made=mast + tower:type=communication, man_made=communications_tower, communication:mobile_phone=yes) and for any man_made feature whose operator is Jazz, Telenor, Zong, Ufone or PTCL/SCO.

Operators: Taken only from the OSM operator, brand, network or name tags. Towers without a recognisable operator tag are shown as Other / not tagged; nothing is guessed or randomly assigned.

Names: Each tower is labelled network + sector + OSM ID, e.g. Jazz H-9 · 7859345509. The sector is the addr:suburb tag when present, otherwise the nearest named sector in OpenStreetMap (within 2.5 km), and the popup says which one it is.

Saved data: The last result is kept in your browser so a reload shows data instantly; the page still fetches fresh data from the API every time.

Tip: Use the two dropdowns, the tabs, or the chips to filter. They stay in sync.
